# FastAPI Demo

This folder contains FastAPI demonstration examples and supporting notebook content.

## Contents

* `fast_api.ipynb` — interactive notebook exploration of FastAPI usage
* `fastapi_demo.py` — example FastAPI application code
* `mp_demo.py` — an additional demo script for multiprocessing or multi-page behavior

## Purpose

The folder is intended to showcase how FastAPI can be used alongside notebook-driven development.

## Notes

* Run the notebook to explore the code, and use the Python scripts as deployable examples.
