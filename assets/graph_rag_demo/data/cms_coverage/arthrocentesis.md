# CMS Coverage — Arthrocentesis
Source: https://example.gov/cms/arthrocentesis
Policy ID: cms-arthro

Coverage: Arthrocentesis (PROC-123) is covered when medically necessary.
Requires diagnosis consistent with joint effusion or adhesive capsulitis (ICD-10 M75.0x).
Imaging is not required if physical exam confirms effusion.
Use modifier -50 if performed bilaterally.
